# Contributing to ResQ AI

Thank you for contributing to open-source emergency response software.

## Development Workflow
1. Fork the repository and create your feature branch:
   `git checkout -b feature/triage-enhancement`
2. Run local tests:
   `npm run build` for frontend
   `pytest` for backend
3. Commit with semantic commits (`feat:`, `fix:`, `docs:`, `refactor:`).
4. Submit a Pull Request with a clear description and testing verification steps.

## Code Standards
- Zero proprietary AI vendor lock-in for core classification.
- Strictly adhere to WCAG AA contrast rules and tactical dark-mode design constitution.
- Never output medical or dispatch assertions as legally binding without supervisory disclaimers.
